Конфигуратор пускорегулирующей аппаратуры — SystemePact M

Путь «а»: выбор отдельных продуктов (автомат защиты двигателя, контактор, тепловое реле) и аксессуаров
Серия M Systeme Electric

Параметры подбора Сначала выбираем базовое устройство, затем аксессуары

Шаг 1. Тип оборудования
Бренд фиксирован: Systeme Electric. Dekraft добавится отдельным шагом.
Шаг 2. Номинальные параметры Подбор по мощности или по току
Используется для расчёта рабочего тока по 3-фазной формуле.
Напряжение питания двигателя (AC-3).
Если известен ток двигателя/цепи — можно подбирать прямо по нему.
— формула: I ≈ P / (√3·U·cos φ·η), cos φ≈0.8, η≈0.9
Шаг 3. Параметры автомата GM2/GM3
Все серии соответствуют ГОСТ IEC 60947-1/2, степень защиты корпуса IP20.:contentReference[oaicite:0]{index=0}
По каталогу: GM2 — 45 мм ширина, GM3 — 55 мм.:contentReference[oaicite:1]{index=1}
Шаг 3. Параметры контактора
MC1D — аналог LC1D, MC1E — компактные контакторы 9–95 А.
Подбор ведём по параметрам AC-3 (двигатели). Значения AC-4/AC-1 — справочные.
Для MC1E доступны только AC-катушки; MC1D поддерживает AC, DC и AC/DC.
Код катушки (B7, E7, M7, BD, BNE и др.) будет добавлен к каталожному номеру.
MC1D — с тепловыми реле MRD; MC1E — с тепловыми реле MRE.
Шаг 3. Параметры теплового реле
MRD — ток 0,1–97 А; MRE — для MC1E 9–95 А.
Для точной привязки можно указать диапазон контактора.
Шаг 4. Аксессуары автомата GM2/GM3 Доп. контакты, расцепители, шины, соединительные блоки и пр.
Фронтальный блок GMAE используется для сигнализации состояния автомата (вкл./откл.).:contentReference[oaicite:7]{index=7}
GMAN — боковой блок доп. контактов, максимум 2 модуля.:contentReference[oaicite:8]{index=8}
Комбинации GMAE + GMAN должны быть в составе 1NO+1NC или 2NO на блок.:contentReference[oaicite:9]{index=9}
GMAM/GMAD используют отдельную группу контактов для выдачи сигнала «автомат отключился по аварии».:contentReference[oaicite:10]{index=10}
Отключает автомат при падении напряжения ниже заданного уровня (защита от просадки/исчезновения питания).:contentReference[oaicite:11]{index=11}
Позволяет дистанционно отключать автомат по сигналу (например, от кнопки «Стоп» или цепи АВР).:contentReference[oaicite:12]{index=12}
Нельзя одновременно использовать расцепитель минимального напряжения GMAU и независимый расцепитель GMAS для одного автомата (см. схему аксессуаров).:contentReference[oaicite:13]{index=13}
Комплект гребенчатых шин для питания нескольких автоматов GM2 от одного ввода.:contentReference[oaicite:14]{index=14}
Готовый блок для жёсткого соединения автомата защиты двигателя с контактором (пускатель без проводов).:contentReference[oaicite:15]{index=15}
GM2MC02 — корпус для выносного монтажа автомата; GM1L3 — ограничитель тока КЗ; GM2APN01 — выносная рукоятка для GM2P/GM2L при установке на дверцу шкафа.:contentReference[oaicite:16]{index=16}
Шаг 4. Аксессуары контактора MC1D/MC1E Доп. контакты, задержки, ограничители перенапряжений, блокировки
Фронтальные блоки MADN увеличивают число вспомогательных контактов для цепей управления и сигнализации.:contentReference[oaicite:17]{index=17}
Боковой блок MAD8N ставится сбоку контактора и также добавляет вспомогательные контакты.:contentReference[oaicite:18]{index=18}
Блоки MADT/MADR дают задержку замыкания/размыкания контактов 1 NO + 1 NC по времени.:contentReference[oaicite:19]{index=19}
MAD4V**/MAD4RC** подключаются к клеммам катушки и подавляют коммутационные перенапряжения. Для MC1D с универсальными катушками AC/DC модуль уже встроен.:contentReference[oaicite:20]{index=20}
Механическая блокировка исключает одновременное включение двух контакторов в реверсивных схемах.:contentReference[oaicite:21]{index=21}
